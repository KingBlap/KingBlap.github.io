KingBlap Kodi Repository

Install add-ons or set up the portable KingBlap build from the October 4, 2026 Kodi snapshot.

Install the repository in Kodi

  1. In Kodi File Manager, add the source https://kingblap.github.io/ and name it KingBlap Kodi Repository.
  2. Open Add-ons → Install from zip file → KingBlap Kodi Repository and select repository.kingblap-1.0.0.zip.
  3. Open Install from repository → KingBlap Kodi Repository.

Android phones, Android TV, and Fire TV Stick

Use the same steps in Kodi on Android. A touch screen or TV remote can navigate the menus; no local download is needed. This repository came from a Windows Kodi 22 snapshot, so Kodi filters its Windows-only native packages on Android. Keep Kodi's official add-on repository enabled so Android ARM versions of binary dependencies can be installed where available. Add-on compatibility and service behavior still vary by add-on, device, and Kodi version.

Install the KingBlap Wizard build

  1. Install or update KingBlap Wizard 1.0.9 from Install from repository → KingBlap Kodi Repository → Program add-ons. This version waits for copied add-ons to register and for the skin to finish loading.
  2. If an older Wizard is already installed and no update appears, choose Add-ons → Check for updates.
  3. Open the wizard, choose KingBlap Kodi Build 1.0.11, and confirm.
  4. Restart Kodi after installation, then enter your own GIPTV provider details.

Build 1.0.11 uses fresh Xonfluence 6.0.6 files for Kodi 22 and includes sanitized skin settings so the skin can load its saved layout. The wizard validates the settings file, switches to Kodi's default Estuary during replacement, waits for Kodi to register the copied add-ons, then installs the settings and waits for Xonfluence to load. It removes the previous Estuary MOD V2 add-on and replaces XStream Player with GIPTV. Account credentials, other add-on profile data, Kodi databases, media libraries, sources, and the profile thumbnail cache are excluded. The skin is marked for all platforms; layouts can vary across Android phones, Android TV, and Fire TV Stick devices.
