Browse and install add-ons packaged from the October 4, 2026 Kodi snapshot.

Install the repository in Kodi

  1. Download the repository installer ZIP to your Kodi device.
  2. In Kodi, open Add-ons → Install from zip file and select the downloaded ZIP.
  3. Open Install from repository → KingBlap Kodi Repository.
